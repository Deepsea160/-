# 工作台（PWA）

本地优先的手机工作台：待办 · 运动 · 记账。

## 功能

- **待办**：快速添加、完成、今日/全部/未完成/已完成筛选
- **运动**：深蹲等次数随手记、步数登记、今日/长期目标与进度
- **账本**：收支流水、分期计划、借入借出台账
- **数据**：全部存本机 IndexedDB，可导出/导入 JSON 换设备

## 本地预览

```powershell
# 任选一种静态服务（Service Worker 需要 http/https）
& $env:MIMO_PYTHON -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

## 安装到手机桌面

1. 将本目录部署到任意静态托管（或局域网 http 服务）
2. **Android Chrome**：菜单 →「安装应用」/「添加到主屏幕」
3. **iOS Safari**：分享 →「添加到主屏幕」

安装后全屏打开，离线可用。

## 备份迁移

设置 → 导出备份 JSON → 新设备设置 → 导入（可选合并或覆盖）。
